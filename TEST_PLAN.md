# API Test Automation Suite

## Objective
Validate the functional, negative, validation, and authentication behavior
of the FastAPI backend.

## Scope
- Health check
- User creation
- User retrieval
- Duplicate user validation
- Authentication
- Invalid input handling

## Test Types
- Functional testing
- Regression testing
- Negative testing
- Edge/validation testing

## Expected Result
All defined test cases should pass and correctly identify unexpected API behavior.
